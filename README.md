# 🎓 CampusNexus (Student Service System)

> A modern, all-in-one peer-to-peer campus ecosystem for college students to exchange **Resources & Notes**, hire **Student Services**, team up on **Project Collaborations**, post **Lost & Found Notices**, and arrange **Campus Carpools**.

---

## 🌟 Expanded Feature Suite

### 1. 📚 Resources & Study Notes Hub
- **Textbooks & Dorm Essentials**: Buy, sell, or lend textbooks, graphing calculators, mini fridges, and lab coats.
- **📑 Study Notes & PDF Reader**: In-browser PDF study guides, exam cheat sheets, and course reviews with instant downloads.
- **🎁 100% Free Giveaways**: Filter for $0 donations passed forward between student years.

### 2. 🎨 Student Services Marketplace
- **Graphic Design & Branding**: Student club posters, Instagram graphics, merch artwork, and Figma UI/UX prototypes.
- **Video & Reel Editing**: Premiere Pro & DaVinci Resolve video editing for campus events, student startups, and social reels.
- **Graduation & Headshot Photography**: 30-min campus portrait sessions at iconic university spots.
- **Resume Reviews & Mock Interviews**: ATS resume feedback, behavioral interview prep, and technical coaching.
- **Language Exchange**: Conversational practice (Spanish, French, Mandarin, etc.) and essay proofreading.
- **Campus Event Assistance**: Stage crew, live sound mixing, PA system setup, and festival coordinators.

### 3. 🚀 Project Collaboration Hub
- **Student Startups**: Find co-founders, mobile developers (React Native/Flutter), and growth leads.
- **Hackathon Teams**: Recruit frontend/ML engineers with specific tech stack badges.
- **Faculty Research Assistantships**: Direct applications for undergraduate lab positions and stipends.

### 4. 📋 Campus Notice Board (Lost & Found)
- Corkboard notice feed for lost and found **Student IDs**, **Notebooks/Binders**, **Tech/AirPods**, and **Keys**.
- Status badges: `🔴 Lost (Seeking)` vs `🟢 Found (Ready for Claim)`.
- One-click claim flow with verification and reward prompts.

### 5. 🚗 Campus Carpools & Ride Sharing
- Carpooling board for weekend airport runs, hackathons, and daily commutes.
- Real-time seat reservation and driver verification.

### 6. 🛡️ Trust, Safety & Campus Cash
- **Interactive Safe Exchange Map**: Blueprint highlighting authorized 24/7 security monitored exchange zones (Library, Student Union, Police Escrow Bay).
- **💳 Digital Campus Cash QR Simulator**: Encrypted QR code generation and instant peer payment simulation.
- **⭐ Peer Reputation & Badges**: Rate transactions (1–5 stars) and award badges (*"Super Helpful"*, *"Fast Responder"*, *"Generous Lender"*).

---

## 🚀 Getting Started

### 1. Run Development Server
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Build for Production
```bash
npm run build
npm run start
```
